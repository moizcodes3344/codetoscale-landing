Technical SEO & Performance Checklist
To ensure the site is fast, indexable, and accessible, implement these optimizations without altering overall
architecture: 
Semantic HTML: Use <header> , <nav> , <main> , <article> , <section> , <footer>  tags
appropriately. One <h1>  per page, then <h2> / <h3>  hierarchically【14†L147-L155】. 
Responsive Design: Verify layout and navigation on mobile (375px, 425px) up to desktop (1440px).
Ensure no horizontal scroll; use media queries for breakpoints 1024px, 768px, 425px, 375px. 
Images: Compress and serve scaled images. Use img srcset  or <picture>  for responsive
images. Include alt  text (descriptive, ≤125 chars【14†L167-L175】). Add loading="lazy"  to
offscreen images. 
CSS/JS: Inline critical CSS (above-the-fold styles) or use a minimal critical CSS file. Defer non-critical
CSS/JS. Use preconnect for required domains (e.g. Google Fonts):
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
Preload Key Assets: Preload web fonts and hero images if needed:
<link rel="preload" href="/fonts/OpenSans.woff2" as="font" type="font/
woff2" crossorigin>
Meta Tags: Include viewport meta
( <meta name="viewport" content="width=device-width, initial-scale=1"> ), charset
( UTF-8 ), and relevant description  and title  tags on each page. 
Canonical URLs: Ensure a <link rel="canonical" href="..."/>  on each page (pointing to
itself)【37†L268-L279】. 
Sitemap & robots.txt: Create sitemap.xml  listing all public URLs and reference it in 
robots.txt  ( Sitemap: https://yourdomain.com/sitemap.xml ). 
Structured Data: Embed JSON-LD for Organization, BreadcrumbList, Service (per service page)
【24†L30-L39】, FAQPage (FAQ page) and possibly BreadcrumbList on all pages to reflect navigation.
Validate via Google’s Rich Results Test【37†L196-L204】. 
Accessibility (WCAG 2.1):
Ensure all images have alt  text【30†L306-L314】. 
Use ARIA roles/labels for any interactive components (e.g. 
<button aria-label="Close menu"> ). 
Ensure tab order: navigation and links should be focusable with keyboard (use button  or a 
href="#"  elements, not plain div ). 
Form labels: <label>  tags for inputs, or aria-label . 
Contrast & text size: meet WCAG AA (contrast ≥4.5:1 for text) (no citation needed, widely known). 
Reduced-motion: if animations exist (e.g. scroll reveals), respect prefers-reduced-motion  media
query to disable or simplify animations for users who opt out.
